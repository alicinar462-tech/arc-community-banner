# Arc Community Banner

A reusable, forkable X/Twitter banner template for the Arc community.

## How it works

1. Fork this repository.
2. Open `index.html` locally or enable GitHub Pages.
3. Enter your **Name, Username, Location, Country, and Chapter**.
4. Download the final **1500 × 500 PNG**.
5. Upload it as your X/Twitter header.

The artwork is fixed while the five community/member fields are customizable. The avatar area remains open so the user's X profile image can sit naturally over the left side.

## GitHub Pages

After pushing the repository to GitHub:

`Settings → Pages → Deploy from branch → main → / (root)`

GitHub will provide a public editor URL that can be shared with Arc community members.

## Files

- `index.html` — browser-based customization tool
- `assets/banner-base.png` — 1500 × 500 base artwork
- `config.json` — default field values / future automation hook

## Important

The Arc branding and artwork should be used consistently with the Arc/Circle brand rules and the competition's official terms.
